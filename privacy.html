mail-warden privacy policy

Last updated: October 10, 2026

Who uses it

mail-warden is a personal tool used only by its owner, Sean Phelan, on his own Gmail account. It has no other users.

What it accesses

With the owner's permission, mail-warden uses the Gmail API to read message headers (sender, recipients, subject, date), Gmail's short preview text and labels, and to apply or remove labels, archive messages and mark them read. It does not store message bodies.

Where data is kept

A small index of message headers and a log of the actions taken are stored on computers the owner controls. The Google sign-in token is stored the same way. Nothing is sent to any other service.

Sharing

No data is sold, shared or transferred to anyone. No data is used for advertising or to train AI models.

Google API Services User Data Policy

mail-warden's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local index removes all stored data.
